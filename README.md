# 🚗 Real-Time Auto Insurance Churn Analysis & Power BI Retention Dashboard

## 📌 Project Overview
This project focuses on analyzing auto insurance customer data to understand churn behavior and support retention decision-making. The work includes data cleaning and preparation using Python, followed by the development of a multi-page interactive Power BI dashboard for business insights.

The dashboard is designed to help insurance teams identify churn-prone customers and explore patterns related to pricing, tenure, claims, and customer segments.

---

## 🧹 Data Preparation
- Cleaned and preprocessed raw insurance customer data using **Python (Spyder)**
- Handled missing values, inconsistencies, and data formatting issues
- Created analysis-ready datasets for visualization and reporting in Power BI

---

## 📊 Power BI Dashboard
Built a **6-page interactive Power BI report** covering:

- Customer churn overview & trends
- Policy tenure and renewal behavior
- Claims frequency and severity analysis
- Pricing and premium-related insights
- Customer segmentation insights
- Retention-focused KPIs and drill-down views

Used Power BI features such as:
- Slicers and drill-through pages
- DAX measures for churn metrics
- AI visuals (Key Influencers, Decomposition Tree)
- Smart Narratives for automated insights

---

## 💼 Business Value
- Helps identify customers at higher risk of churn
- Supports data-driven retention strategies
- Enables business users to explore churn drivers interactively
- Demonstrates practical analytics and dashboarding skills
